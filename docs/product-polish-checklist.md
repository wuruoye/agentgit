# AgentGit 产品缺陷与打磨清单

本清单服务于固定循环：审查 → 清单 → 修复 → 验证 → 复审。每项只有在真实 App 中完成
深浅色、窄窗口、键盘、焦点、无障碍和性能复审后才能勾销。

## P0：Review 主路径

- [x] 建立清晰的分组标题、文件标题、hunk 标题、代码内容四级视觉层次；分组与文件标题保持
  吸顶，hunk 标题与行范围可读，操作按钮不挤压窄窗口内容。
- [x] `Files` 导航按目录树展示改动，文件夹可独立展开和收起，筛选结果自动展示完整祖先路径。
- [x] 新 Review 默认收起全部文件内容；点击文件后展开对应 diff；新增文件默认收起，已经存在
  的用户展开状态在刷新后保持。
- [x] 前后台切换与后台启动保持当前 worktree、History 搜索 context、ReviewState 和缓存内容；
  搜索恢复期间继续展示当前 Review，不回退到 Pending Changes。
- [x] 使用真实大仓库复审长文件名、深目录、重复文件名、Working/Staged 同路径、Commit 与
  Commit Range；40,000 个文件的树构建保持低于一秒。
- [x] 复审 unified / split；split 左右栏分别裁剪绘制，右栏不会覆盖旧代码；每个 hunk 独立
  横向滚动，上下文展开、Whole File 切换和滚动锚点保持稳定。
- [x] 文件标题下方提供独立的 Whole File 两态按钮；收起时显示完整文件，展开后恢复只显示修改
  hunk，切换期间保持当前代码位置。
- [x] diff 代码支持按字符拖动选择，按钮和文件折叠仍保持独立点击区域。

## P1：日常 Git 工作流

- [x] 逐项复审 Stage、Unstage、Discard 的文件、hunk、行操作及原按钮二次确认。
- [x] 逐项复审 Pull、Push、取消、upstream 缺失、分叉分支和远端错误反馈。
- [x] 复审 History 分页、提交搜索、文件定位、键盘导航和长提交信息。
- [x] 复审侧栏项目拖拽、worktree 排序、四项折叠规则、搜索、右键菜单和缓存恢复。

## P1：窗口与系统体验

- [x] 复审 Settings、错误条、空态、加载态和恢复操作的视觉层级与文案。
- [x] 最小窗口支持 `980×600`；侧栏、导航与 Review 同时保持可见，文件操作不越界；Review
  分栏支持鼠标拖动和 VoiceOver 增减调节，并通过深色与高对比度渲染检查。
- [ ] 复审主路径完整键盘操作与 VoiceOver 阅读顺序，补齐 Stage、Unstage、Discard 和 Review
  导航的焦点反馈。
- [x] 后台空闲 CPU 接近零；大型仓库状态刷新使用 Git 性能缓存和变更路径范围内的 diff
  统计，长历史和大 diff 保持可取消、可增量、无主线程卡顿。
